# СМАРТ Маркет (Smart Market • Одесса)

> **Современное мобильное Android-приложение** (Jetpack Compose + Material 3) и веб-платформа на **Supabase Cloud + FastAPI**: AI-маркетплейс спроса и предложений с поиском по естественному языку, умной анкетой, рубрикой «Хорошая цена» (-25%+ от медианы), Location-First ранжированием по районам Одессы и монетизацией через Google AdMob.

---

## 🌟 Ключевые возможности

1. **Два режима на главном экране:**
   * **🔍 Ищу / Куплю (Demand):** Быстрый поиск предложений по описанию своими словами (*«Нужен генератор 5 кВт до 40 000 грн на Таирова»*).
   * **📦 Предлагаю / Продам (Supply):** Размещение своих товаров/услуг с мгновенным показом подходящих покупателей (*«Сдам 2к квартиру в Аркадии 15 000 грн»*).
2. **Двуязычный AI-парсер (UA / RU):**
   * Автоматически извлекает категорию, числовые параметры (мощность кВт, комнатность, этаж), бюджет и район Одессы.
3. **Универсальная «Умная анкета» (Smart Form):**
   * Нейросеть предзаполняет параметры из текста.
   * Пользователь может в 1 клик поправить значения и прикрепить фотографии (Photo Picker).
4. **Location-First Matching (Одесса):**
   * Расчет расстояния по формуле Haversine по микрорайонам (Таирова, Аркадия, Центр, Черёмушки, Большой Фонтан, Пос. Котовского).
   * Приоритет ближайшим предложениям (*«📍 1.2 км от вас»*).
5. **Монетизация и переходы (Google AdMob):**
   * **Свои объявления:** Бесплатный прямой звонок продавцу в 1 клик (`ACTION_DIAL`).
   * **Внешние объявления (OLX, Prom, DOM.ria):** Показ спонсорской рекламы Google перед переходом к источнику.
   * **Нативная реклама в ленте:** Интегрированные AdMob-карточки среди результатов поиска.
6. **Дизайн и темы:**
   * Поддержка **Светлой** и глубокой **Тёмной** (OLED-friendly) тем с переключением на лету.
   * 100% нативный Material 3, скругленные формы, плавная анимация.
7. **Сохранение спроса и Push-уведомления:**
   * Кнопка сохранения запроса для фонового уведомления при появлении новых предложений поблизости.

## 📱 Сборка Android-приложения

Готовый собранный Debug APK находится в:
```
app/build/outputs/apk/debug/app-debug.apk
```

Для сборки через консоль:
```powershell
$env:JAVA_HOME = "C:\Users\user\AppData\Local\Java\jdk-21.0.6+7"
.\gradlew.bat assembleDebug
```

Для генерации релизного бандла под Google Play Console:
```powershell
.\gradlew.bat bundleRelease
```

## ⚡ Бэкенд (FastAPI)

В папке `backend/` реализован сервис:
- `POST /api/v1/intents/parse` — AI-нормализация текста и извлечение параметров.
- `POST /api/v1/matches` — Location-First сопоставление с учетом гео-координат.
- `GET /api/v1/districts` — Список районов Одессы.

Запуск бэкенда:
```powershell
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```
