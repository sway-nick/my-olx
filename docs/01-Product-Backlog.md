# Product Backlog — IntentMarket («Мой OLX»)

## Epic 1. Core Intent Engine (Поиск и Размещение)

### Feature: DEMAND Flow («🔍 Ищу / Куплю»)
- [x] Ввод естественным языком в единое поле ввода.
- [x] Двуязычный AI-парсер (UA / RU) для категорий: Генераторы, Аренда квартир, Услуги, Электроника.
- [x] Автоматическое извлечение мощности (кВт), комнатности, топлива, бюджета и района Одессы.
- [x] Быстрые подсказки-чипсы популярных запросов.
- [x] Сохранение устойчивого спроса (`Persistent Demand`) с подпиской на Push-уведомления.

### Feature: SUPPLY Flow («📦 Предлагаю / Продам»)
- [x] Режим предложения с отдельным плейсхолдером и действием.
- [x] Обратный матчинг в реальном времени: мгновенный показ найденных покупателей (*«В вашем районе 3 человека ищут этот товар»*).
- [x] Загрузка и превью фотографий товара (Photo Picker UI).

### Feature: Universal Smart Form («Умная анкета»)
- [x] Экран предзаполнения параметров от AI с возможностью быстрой ручной корректировки.
- [x] Динамические поля под категорию (мощность/топливо для генераторов, комнатность/этаж для жилья).
- [x] Выбор района Одессы (Таирова, Аркадия, Центр, Черёмушки, Фонтан, Котовского).

---

## Epic 2. Location-First Matching Engine

### Feature: Geo-Distance & Scoring
- [x] Расчет расстояния по PostGIS `ST_Distance` / формуле Haversine.
- [x] Градация релевантности: `EXCELLENT` (Отлично подходит), `GOOD` (Подходит), `PARTIAL` (Частично подходит).
- [x] Приоритет вариантов в радиусе до 3–5 км с адаптивным расширением на город/область.
- [x] Отображение бейджей дистанции (*«📍 1.2 км (Таирова)»*).

---

## Epic 3. External Supply Layer (Агрегация)

### Feature: Источники и Провенанс
- [x] Строгая изоляция внешних предложений (`external_listings`) от внутренних (`listings`).
- [x] Сохранение источника (OLX, Prom, DOM.ria), времени парсинга и прямой ссылки.
- [x] Статусы актуальности: `FRESH`, `STALE`, `EXPIRED`, `REMOVED`.
- [x] Соблюдение законности: никаких обходов CAPTCHA/anti-bot/rate limits.

## Epic 4. Monetization (Монетизация Google AdMob)

### Feature: Рекламная модель
- [x] 0% комиссии с пользователей и продавцов.
- [x] Native In-Feed Ads: нативные рекламные карточки в ленте выдачи с маркировкой «Реклама».
- [x] Rewarded / Interstitial Ad Notice: предупреждение и спонсорский просмотр перед переходом к внешнему источнику.
- [x] Бесплатный прямой звонок для внутренних объявлений платформы (`Intent.ACTION_DIAL`).

## Epic 5. Trust & Safety (Google Play UGC Compliance)

### Feature: Модерация и Безопасность
- [x] Механизм жалоб (`public.reports`) на нежелательный контент/мошенничество (Google Play Policy 4.7).
